Morph Pad

Drag the crosshair to blend a block between five tones: one in the centre, a different voicing in each corner. Every parameter of the model moves, knobs blend and switches change at the halfway point, and the block follows slowly, so a fast move becomes a smooth sweep.

Edit buffer only. Connected, the pad moves the block's parameters live, the way POD Go Edit does. Nothing is saved: the preset shows as edited, and reloading it on the unit puts everything back. Quit POD Go Edit first; use Chrome or Edge on a computer.

Not connected: the pad runs as a simulation.

Default tones are Line 6's own Focus View presets, five per model, plus our own gentle sets for the EQs and two delays that have none: 514 of the POD Go's models in all, every one that suits morphing, and the pad recognises those blocks by itself. For cabs, loops and the other blocks, load the model list from your own copy of POD Go Edit (on a Mac: Applications › Line6 › POD Go Edit › Show Package Contents › Contents › Resources › PodGo.sym); it is read in this browser and kept there.

Edit the five tones

Changes are kept in this browser, per model. Blend parameters are averaged; pick parameters (switches, selectors) take the value of the tone with the most weight; fixed ones are left as they are on the unit. Level the five tones with Ch Vol so the sweep doesn't jump in loudness.

How it works

  • Each model has its own set of five tones: a centre and four corners, each with a name and a value for every parameter it sets. Tone files use one JSON shape: {modelName, params: {Name: {behavior}}, regions: {origin, x_min_y_max, x_max_y_max, x_min_y_min, x_max_y_min}}, top left, top right, bottom left, bottom right.
  • The centre tone's share is (1 − |x|)·(1 − |y|); the rest is split between the corners by bilinear weighting, so an edge blends only its two corners and each tone's own spot plays that tone exactly.
  • Glide moves the real position towards the crosshair with a time constant. Only parameters that changed are sent, one message at a time, at most 30 batches a second.
  • Tones come from your own edits first, then tone files you imported, then the defaults (Line 6's Focus View tones, or ours for the EQs and two delays). A model with none starts with all five set to the block as it is on the unit: edit them, or copy the block into a tone after dialling it in on the unit.
